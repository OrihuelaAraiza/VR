# VR

Repositorio de laboratorios de Realidad Virtual y Realidad Aumentada desarrollados con Unity para iPad/iOS.

## Laboratorios

- `Labo1/Labo1`: primer laboratorio de seguimiento de imágenes con AR Foundation y ARKit.
- `Labo 2`: seguimiento simultáneo de dos imágenes, con un cubo y una esfera asignados por nombre.

## Requisitos

- Unity 6.5.0f1.
- Xcode con soporte para iOS.
- iPad compatible con ARKit para las pruebas físicas.

Cada laboratorio conserva sus carpetas `Assets`, `Packages` y `ProjectSettings`. Las bibliotecas, compilaciones, logs, archivos de IDE y demás contenido regenerable están excluidos del repositorio.
